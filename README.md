# CS2 死后自动狡辩

死了就自动打开聊天框甩锅找借口的整活小工具。

## 原理

用 CS2 官方的 **Game State Integration (GSI)**：游戏主动把你的血量/存活状态
POST 到本地端口，脚本检测到"我刚死"就自动发一句借口。

- ✅ 不读游戏内存、不注入进程 —— 走 Valve 官方接口，不触发 VAC
- ✅ 中文借口靠"剪贴板 + Ctrl+V 粘贴"发送，稳
- ⚠️ 自动发聊天本质是刷屏行为，可能被队友举报/禁言，建议在休闲局/自建服玩，风险自负

## 安装

1. 装 Python 3.8+，然后装依赖：
   ```
   pip install -r requirements.txt
   ```

2. 把 `gamestate_integration_diebrag.cfg` 复制到 CS2 的 cfg 目录，通常是：
   ```
   ...\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
   ```
   （找不到的话在 Steam 里右键 CS2 → 管理 → 浏览本地文件，再进 `game\csgo\cfg`）

## 使用

1. 双击 `启动.bat`，会开一个黑窗口显示运行状态（死亡记录等）。
2. 启动 CS2，进入任意对局。死了就会自动狡辩。
3. 关掉黑窗口或按 `Ctrl+C` 停止。

## 改借口（增 / 删 / 改句子）

借口都放在 **`excuses.txt`**，一行一句。两种改法，随便选：

- **图形界面**：双击 `编辑借口.bat`，弹出窗口后——
  - 下方输入框打字 → 点「添加」
  - 选中某条 → 点「删除选中」
  - 双击某条 → 修改内容
  - 所有改动**自动保存**，无需另外点保存
- **记事本**：右键 `excuses.txt` → 用记事本打开，直接加/删行。`#` 开头的行是注释会被忽略。

改完**立即生效**，主程序下次触发就用新内容，不用重启。

## 其它自定义

打开 `cs_die_brag.py` 顶部的配置区：

- `CHAT_KEY`：`'y'` 全局聊天 / `'u'` 队伍聊天（要和你游戏里的绑定一致）
- `COOLDOWN`：两条之间最短间隔
- `DELAY_OPEN_CHAT` / `DELAY_AFTER_PASTE`：掉帧/网速慢时调大一点

## 排错

- **不发消息**：确认游戏里 `y`/`u` 确实是打开聊天的键；确认 cfg 放对目录且端口和脚本一致（都是 3000）。
- **粘贴出乱码/发空**：把 `DELAY_OPEN_CHAT` 调到 0.3 左右，有些机器聊天框弹出慢。
- **管理员权限**：如果 CS2 以管理员运行，脚本也要用管理员运行，按键才发得进去。
- **完全没反应**：先看脚本控制台有没有打印心跳/死亡日志。没有说明 GSI 没连上（cfg 没放对）。
